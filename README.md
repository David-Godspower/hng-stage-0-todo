# HNG14 Stage 0 - Testable Todo Item Card

A high-fidelity, accessible, and responsive Task Card component built for the HNG14 Stage 0 Frontend track.

## Features
- **Semantic HTML:** Built using `<article>`, `<time>`, and proper heading structures.
- **Accessibility:** Includes ARIA labels for icon-only buttons and screen-reader-only labels for inputs.
- **Real-time Countdown:** JavaScript logic updates the "Time Remaining" hint every 30 seconds.
- **Responsive Design:** Fully fluid layout using Tailwind CSS, optimized from 320px to 1200px.
- **Test-Ready:** Implements all required `data-testid` attributes for automated grading.
